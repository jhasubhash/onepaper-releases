# OnePaper releases

Downloads and the update feed for **OnePaper**, a Craft-style notes app for Mac, iPad and iPhone, built for code and machine-learning notes.

## Mac

Download the latest `OnePaper-x.y.z.dmg` from [Releases](https://github.com/jhasubhash/onepaper-releases/releases/latest), open it and drag OnePaper to Applications. Builds are signed with Developer ID and notarized by Apple. The app checks for updates on its own, or use **OnePaper › Check for Updates…**

Requires macOS 26 or later.

## iPhone and iPad

Distributed through TestFlight.

---

`appcast.xml` is the [Sparkle](https://sparkle-project.org) update feed read by the Mac app; every update is EdDSA-signed.
